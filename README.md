# GitHub to Jenkins Integration Practice

This project is created to practice the workflow of uploading code from Eclipse to GitHub and integrating it with Jenkins for Continuous Integration (CI).

## Workflow
1. Develop project in Eclipse
2. Push source code to GitHub
3. Connect GitHub repository with Jenkins
4. Build and test project automatically using Jenkins

## Tools & Technologies
- Eclipse IDE
- Git & GitHub
- Jenkins
- Java

## Features
- Version Control using GitHub
- Automated Build Process
- Continuous Integration Practice
- Simple CI/CD Workflow

## Objective
To understand the integration between Eclipse, GitHub, and Jenkins and learn the basics of Continuous Integration.

## Purpose
Created for practice and learning DevOps workflow concepts.
